# สรุปสเปก Songdle ฉบับภาษาไทย

**สถานะ:** เอกสารสำหรับวางแผนและส่งต่อให้ Coding Agent — ยังไม่ใช่ระบบที่เขียนเสร็จหรือผ่านการทดสอบบน Production

## ภาพรวมโปรเจกต์
Songdle คือเว็บเกมทายเพลงไทยที่เน้น T-Pop เล่นผ่าน Browser ได้ทั้งมือถือและคอมพิวเตอร์ ใช้ Next.js + TypeScript ทำ Frontend, Go เป็น REST Backend และ PostgreSQL เก็บข้อมูลจริง ส่วน Redis เก็บไว้ใช้เมื่อมีโจทย์ Cache หรือ Leaderboard ในภายหลัง

### ข้อกำหนดหลักที่ผู้ใช้เลือกแล้ว
| หัวข้อ | ข้อกำหนด |
|---|---|
| เพลง | เพลงไทยแนว T-Pop เป็นหลัก |
| โหมดที่ 1 | ฟังคลิปและทายชื่อเพลง (Guess the Song) |
| โหมดที่ 2 | ฟังคลิปและทายศิลปิน (Guess the Artist) |
| คลิปเสียง | ความยาวคงที่ 10 วินาที |
| การตอบ | พิมพ์ค้นหาแบบ Autocomplete และเลือกคำตอบจากรายการด้วย ID |

### กติกา MVP ที่ใช้เป็น Baseline
- เริ่มเกมได้ทันทีในฐานะ Guest โดยไม่ต้องสมัครสมาชิก
- หนึ่งรอบสุ่มเพลงหนึ่งเพลง ผู้เล่นเลือกโหมดก่อนเริ่ม
- กดฟังคลิป 10 วินาทีซ้ำได้ไม่จำกัด ไม่มีจับเวลา
- ตอบได้สูงสุด **5 ครั้งที่ถูกต้องตามรูปแบบและไม่ซ้ำกัน**
- ตอบถูกครั้งที่ 1–5 ได้ **100 / 80 / 60 / 40 / 20 คะแนน** ตามลำดับ หากทายผิดครบ 5 ครั้งได้ 0 คะแนน
- คำตอบผิดหักโอกาสหนึ่งครั้ง แต่คำตอบที่ไม่ถูกประเภท / ไม่มีในฐานข้อมูล / เคยตอบแล้ว / การส่งซ้ำเพราะเน็ตหลุด **ไม่หักเพิ่ม**
- Backend เป็นผู้ตรวจคำตอบ คิดคะแนน และเปลี่ยนสถานะเกมทั้งหมด
- เมื่อชนะหรือแพ้ แสดงเฉลยและประวัติคำตอบ พร้อมปุ่มเริ่มรอบใหม่

## การทายชื่อเพลงกับการทายศิลปินต่างกันอย่างไร
- **โหมดทายชื่อเพลง:** ส่ง `song_id` ที่เลือกจาก Autocomplete และตรวจเทียบเพลงเป้าหมายของรอบนั้น
- **โหมดทายศิลปิน:** ส่ง `artist_id` และตรวจว่าศิลปินนั้นถูกระบุเป็นคำตอบที่ยอมรับของเพลงเป้าหมายหรือไม่
- เพลงหนึ่งเพลงมีหลายศิลปินได้ เช่น ศิลปินหลักและศิลปิน Featuring จึงต้องมีตารางเชื่อม `song_artists` ที่กำหนด `is_accepted_answer` เป็นรายเพลง ไม่ใช้การเดาจากชื่อหรือเครดิต

## โครงสร้างข้อมูลหลัก 6 ตาราง
1. `songs` — ชื่อเพลง แนวเพลง สถานะ และข้อมูลทั่วไป
2. `artists` — ข้อมูลศิลปินและข้อความค้นหา
3. `song_artists` — ความสัมพันธ์หลายต่อหลาย พร้อมบทบาทเครดิตและ flag ว่ายอมรับเป็นคำตอบได้หรือไม่
4. `audio_clips` — ตำแหน่งคลิป 10 วินาทีและหลักฐานสิทธิ์การใช้งาน
5. `game_sessions` — รอบเกม สถานะ `PLAYING/WON/LOST` เพลงที่ถูกสุ่ม จำนวนครั้งและคะแนน
6. `guesses` — ประวัติคำตอบแต่ละครั้ง พร้อม idempotency key ป้องกันส่งซ้ำ

**ข้อควรระวัง:** `game_sessions.song_id` เป็นเฉลย ต้องอยู่ฝั่ง Server เท่านั้นระหว่างเล่น ห้ามส่งชื่อเพลง รายชื่อศิลปินที่ถูกต้อง หรือข้อมูลไฟล์ที่ใช้เดาเฉลยได้ใน API/URL/Metadata ก่อนเกมจบ

## API ที่วางไว้ (ยังเป็น Proposed Contract)
| Method | Path | ความหมาย |
|---|---|---|
| POST | `/api/v1/games` | สร้างรอบเกม |
| GET | `/api/v1/games/{id}` | ดึงสถานะ/เล่นต่อหลัง Refresh |
| POST | `/api/v1/games/{id}/guesses` | ส่งคำตอบและรับผลที่ Backend ตรวจแล้ว |
| GET | `/api/v1/songs/search?q=` | ค้นหาชื่อเพลงสำหรับ Autocomplete |
| GET | `/api/v1/artists/search?q=` | ค้นหาศิลปินสำหรับ Autocomplete |
| GET | `/api/v1/games/{id}/audio` | เล่นคลิปที่ได้รับอนุญาตผ่าน URL แบบไม่เปิดเผยข้อมูลเพลง |

## การทดสอบที่ต้องมี
ตรวจอย่างน้อยว่า: ทั้งสองโหมดเล่นจบได้, คะแนนทั้ง 5 กรณีถูกต้อง, คำตอบซ้ำไม่หักจำนวนครั้ง, การยิงคำขอพร้อมกันไม่ทำให้ทายเกิน 5 ครั้ง, Guest คนอื่นเปิดรอบเกมไม่ได้, Refresh ไม่เสียข้อมูล, ระบบไม่เปิดเผยเฉลยก่อนจบ, แสดงสถานะโหลดเสียงล้มเหลวได้ และ Autocomplete ใช้คีย์บอร์ดกับภาษาไทยได้

## Roadmap ที่เหมาะสำหรับ Agentic Coding
- **M0:** เตรียม Monorepo, Docker Compose, Linter, CI และยืนยันการใช้ไฟล์เสียงทดสอบที่มีสิทธิ์
- **M1:** สร้าง PostgreSQL Migrations, Seed ข้อมูลจำลองและ Search API
- **M2:** ทำ Go Game Engine, Guest Sessions, Score, Guess Validation, Transaction/Idempotency และ Audio Endpoint
- **M3:** ทำ Next.js UI สำหรับเริ่มเกม ค้นหาคำตอบ ฟังเพลง ดูผล และเล่นต่อหลัง Refresh
- **M4:** ทดสอบความปลอดภัย ความทนทาน Accessibility, Deploy และ README สำหรับ Portfolio

## สิ่งที่ยังไม่ควรทำใน MVP
ไม่ต้องทำ Login, Daily Challenge, Leaderboard, Multiplayer, ระบบเพื่อน, Achievement, Hint หรือคลิปที่ยาวขึ้นตามจำนวนครั้ง และ **ไม่ต้องบังคับใช้ Redis** เพื่อให้เกมทำงานได้

## เงื่อนไขที่ต้องเคลียร์ก่อนเผยแพร่จริง
แหล่งเสียงเพลงต้องได้รับอนุญาตสำหรับวิธีใช้งานที่เลือก ทั้งการตัดคลิป 10 วินาที การเก็บไฟล์ การ Streaming และการเผยแพร่ ไม่มีข้อสันนิษฐานว่าเพลงเชิงพาณิชย์นำมาใช้ในโปรเจกต์ได้โดยอัตโนมัติ หากยังยืนยันสิทธิ์ไม่ได้ ให้สาธิตด้วยเสียงสังเคราะห์หรือไฟล์ที่อนุญาตแทน
